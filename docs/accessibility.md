# Accessibility plan

Required checks include semantic labels for controls and plots, keyboard navigation,
focus order, contrast, large text, dark theme, TalkBack, VoiceOver and desktop screen
readers. Plot data must have a non-visual representation, and series must use more
than color alone.

Every feature must define empty, loading, success and error states. Error messages
must explain what the user can change. Reduced-motion settings remove decorative
movement while keeping required state feedback.
