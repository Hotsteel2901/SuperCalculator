# SuperCalc Android 底部导航信息架构设计

## 目标
解决当前 `CalcActivity` 单页长滚动表单带来的认知负荷与操作效率问题，将功能按场景分组，通过底部导航快速切换。

## 现状
- 所有功能堆叠在一个 `NestedScrollView` 内，约 30+ 张卡片。
- 用户需要大量滚动才能找到功能。
- `CalcActivity.java` 超过 5000 行，逻辑高度集中。

## 设计方案
### 信息架构（4 个底部导航项）
1. **计算**：表达式输入、结果、快速选择、自定义函数、参数、基础运算（求值/导数/积分/求解/极值/根/极限/泰勒/FFT/弧长等）。
2. **绘图**：ODE、方向场、向量场、等高线、旋转体体积、非线性方程组、参数曲线、极坐标、隐函数、函数图像。
3. **统计**：统计量、统计分布、曲线拟合。
4. **工具**：矩阵、数论、位运算、进制转换、单位换算、万年历、概率、金融、数据导入、插值、拉普拉斯变换。

### 技术方案
- 在当前 `activity_calc.xml` 中，用 4 个 `LinearLayout` 容器包裹对应卡片。
- 新增 `BottomNavigationView`，绑定 `menu/bottom_nav_menu.xml`。
- 在 `CalcActivity.java` 中根据选中项切换容器可见性（`View.VISIBLE` / `View.GONE`）。
- 不拆分 Fragment/Activity，保持现有事件绑定与计算逻辑不变，降低回归风险。
- 选中状态、滚动位置通过 `onSaveInstanceState` 保存。

### 视觉与交互
- 底部导航固定在最底部，高度约 80dp；内容区预留 `paddingBottom` 避免被遮挡。
- 当前选中项使用主题主色高亮。
- 切换时无动画，保证响应速度；后续阶段可补淡入淡出。

## 后续阶段（不在本次范围内）
- 第二阶段：输入体验（数学键盘、历史、自动补全）。
- 第三阶段：结果与可视化（统一结果卡片、图表交互）。
- 第四阶段：性能与稳定性（异步计算、状态保存）。
