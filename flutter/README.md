# SuperCalculator - Next Era Flutter app

This directory is the incremental Flutter application. It is intentionally kept
beside the legacy Python, Android and Web entry points until feature parity and
rollback checkpoints are accepted.

## Local setup

1. Install the stable Flutter SDK recorded in `../docs/migration/m0-baseline.md`.
2. Run `flutter pub get`.
3. Run `flutter gen-l10n`.
4. Run `flutter run -d chrome` or select a native device.
5. Run `flutter analyze` and `flutter test`.

The native shared library is optional during M1. If it is not present, the app uses
the bounded Dart fallback. Build the additive C ABI with `../tool/build_native.sh`.

Platform project folders are generated by Flutter for the target release channel;
the checked-in `lib`, `web`, assets, tests and configuration are the stable source
of truth while the migration is in progress.
